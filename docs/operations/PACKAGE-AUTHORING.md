# Bounded package authoring

## Artifact contract

Version 3 adds inline UTF-8 artifacts to the existing work-package graph. Groom authors the graph, child plans, specifications and checks inside its already-authorized specification artifact. It does not acquire permission to write those child files into the caller repository.

`scripts/nightshift-package-bundle.py` projects only declared inputs into a disposable validation directory and applies the canonical version 2 validator. Parent/preparation controls, routing/settings, private runtime paths, aliases, symlinks, undeclared artifacts and conflicting existing caller content are rejected. The serialized bundle and total projected bytes have separate limits; neither is truncated. Child execution consumes the validated plans and materializes inline bytes only into isolated child repositories. Accepted architecture retains its original authority and history.

The author and independent challenger receive the version 3 schema. Its hash binds operation dependencies. Challenge sees inline contents and declared external inputs, so matching requirement IDs alone cannot approve a decomposition. Templates do not contain authority or prior approval.

## Preparation wall receipts

Preparation records its start, deadline, covered calls and attempts, completion and full active elapsed time. This includes deterministic validation and I/O, not merely provider execution. A crash preserves an unknown phase and its original deadline. The same phase can reconcile retained operation evidence without another dispatch. A completed cache replay adds no new phase duration.

Composition subtracts completed preparation spans from the parent wall allowance before reserving sequential child deadlines. The composition deadline is fixed at authorization; duplicate requests do not refresh it. Idle time between completed preparation and a new composition authorization is not active preparation time; idle time after composition authorization consumes its fixed deadline.

Unmeasured standalone preparation requires reconciliation. It is not assigned a fabricated zero duration. Completed receipts must cover the current assessed evidence and every retained preparation call and attempt before parent authorization.
