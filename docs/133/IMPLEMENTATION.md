# Implementation and validation

Issue: https://github.com/doctor-ew/nightshift-community/issues/133

## Changes

The controller permits unsealed development proof at Implementation entry and requires sealed proof afterward. Adversarial review records complete case classification against immutable, attempt-specific evidence. Stage identity includes policy, relevant route dependencies and the authority helper closure. Infrastructure failures retain accounting without becoming substantive product findings.

Local extraction is admitted only when the configured model is installed. Automatic routing promotes unavailable local work to the configured subscription route; explicit local requests fail closed. Successful Codex login diagnostics tolerate only the known PATH warning. Active Codex defaults use gpt-6.1-sol.

New ticket wall clocks are opt-in. Existing deadlines, explicit limits, active-time and call ceilings remain enforced. Handoffs carry bounded whole-file snapshots and compact failure summaries. Managed stages require canonical controller handoff and receipt paths before receiving Git metadata access.

Branchless controller tickets appear in the dashboard with their receipts and blockers. Their dashboard mutation endpoints reject requests before dispatch.
