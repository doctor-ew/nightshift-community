# Security reporting

Do not publish secrets, exploit details or personal information in public issues.
Use [GitHub private vulnerability reporting](https://github.com/doctor-ew/nightshift-community/security/advisories/new).
If unavailable, request a private channel from the maintainer without posting details.

Include the affected revision, impact and a minimal reproduction. Only test systems
you own or have permission to test. Rotate compromised credentials: removing a
file does not revoke a secret.

Nightshift is an engineer pilot, with no promised security response SLA. Use trusted
practice repositories without production credentials. Agent instructions and
passing tests are not a containment guarantee.
